# Replication package for: *Tipping the Tax: How Government Surcharges Become Gratuities*

**Tyler Sotomayor and Gabriel Uceda-Sosa** (Columbia University), 2026. Working paper.

- Paper: [`main.pdf`](main.pdf)
- Poster: [`poster/tipping-the-tax-poster.pdf`](poster/tipping-the-tax-poster.pdf)
  (PREDOC Summer Research Conference, University of Chicago Booth School of Business, July 30–31, 2026)
- Interactive companion: <https://tylersotomayor.github.io/tipping-the-tax-companion/>
- Contact: tyler.sotomayor@columbia.edu · gu1245@columbia.edu

## Overview

New York taxi payment screens compute suggested tips as percentages of a
fee-inclusive total, so every government surcharge on the meter raises every
suggested tip. This package reproduces the paper's estimate of the causal
pass-through of statutory charges into gratuities — about eleven cents per
legislated dollar, stable across six sources of quasi-experimental variation —
and the fiscal accounting built on it.

Running `./reproduce.sh` rebuilds any missing inputs from the public trip
records, runs the entire Stata pipeline (every table and figure in the paper),
and compiles the paper.

## Data availability and provenance

The raw data are the **public NYC Taxi & Limousine Commission trip records**,
published monthly at:

```
https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_YYYY-MM.parquet
```

Raw parquet files are **not redistributed** here; the builders in `code/py/`
download the required months on demand into `data/raw/` and aggregate them
into estimation cells with fixed, documented filters. The builders are
deterministic: two machines running the same builder produce identical cells.

Two kinds of derived cells:

- **Committed** (small, in `data/cells/`): zone- and route-level panels and
  summary cells (`cells_zone_v2.csv`, `cells_odpair.csv`, `spikes.csv`, …).
- **Rebuilt on demand** (large, gitignored): the minute-grain cells
  (`cells_minute*.csv`, 20–50 MB each). `reproduce.sh` builds any that are
  missing before the Stata pipeline runs. `code/00_master.do` refuses to run
  with missing inputs rather than estimate on stale data.

Tips are observed for card payments only; no rider or driver identifiers
exist anywhere in the data.

## Requirements

- **Stata 18+** (BE is sufficient). Packages:
  `ssc install reghdfe ftools boottest sdid`
  `run_stata.sh` auto-discovers the Stata binary under `/Applications`;
  override with `STATA=/path/to/stata ./reproduce.sh` on other systems.
- **Python 3.10+** with `duckdb` (`pip install duckdb`) for the cell builders.
- **TeX Live** (pdflatex + biber) for the paper.

## One-button replication

```bash
./reproduce.sh                # everything: cells (if missing) → Stata → paper
./reproduce.sh --cells-only   # just rebuild the unversioned input cells
./reproduce.sh --no-paper     # pipeline only, skip the LaTeX build
```

Expected runtime: cell rebuilding is download-dominated (≈30–60 minutes on a
fast connection, ~36 monthly parquet files); the Stata pipeline takes roughly
an hour; the paper builds in about a minute. Every number reported in the
paper is written to `logs/stata-master.log` by the pipeline.
